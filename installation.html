Installation Journey

From an Empty Shaft to a Finished Cabin

Every villa elevator is engineered to a specific shaft, so the exact drawings differ project to project — but the installation itself follows the same path. Here's what it actually looks like.

→ The Process

Four Stages, One Shaft

01 / 04

Pit & Shaft Preparation

Work starts from the shaft you already have — pit depth, overhead height and floor openings are checked against the drawing before anything is fitted.

02 / 04

Structure & Guide Rails

The shaft or drive structure and guide rails go in first, fixed to the building rather than freestanding — this is what carries the cabin's full load.

03 / 04

Cabin & Running Gear

The cabin is set onto its running gear and aligned against the rails, then the decoration package — walls, ceiling, floor and doors — is fitted inside it.

04 / 04

Commissioning

Call panels, safety systems and the door interlock are tested floor by floor before the elevator is handed over.

The Result

Four stages, one shaft — and an elevator that looks like it was always part of the house.
